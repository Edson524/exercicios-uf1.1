# Exercício Prático: Ovos Moles de Aveiro 🥚

Hoje pusemos o nosso portefólio no Git e no GitHub, e demos-lhe uma fotografia, uma abreviatura e um testemunho. Agora é a vossa vez: vão guardar os vossos exercícios no GitHub, acrescentar uma imagem à página da vossa cidade e construir sozinhos uma página sobre um doce tradicional.

O vosso objetivo é repetir sozinhos o ciclo do Git (`add`, `commit`, `push`) e usar imagens, atributos e os novos elementos (`abbr`, `span`, `blockquote`, `div`).

Os ficheiros de que precisam estão na pasta [`ex-003/`](./ex-003/): `ovos-moles.txt`, `imagens/cidade.svg` e `imagens/ovos-moles.svg`.

### Missão 1: Os Exercícios Também no GitHub

1. No VS Code, abram a pasta `exercicios-uf1.1` (**File** → **Open Folder...**) e abram um terminal (**Ctrl + `**).
2. Confirmem com `pwd` que o caminho acaba em `exercicios-uf1.1`.
3. Criem o repositório e o primeiro commit:
   - `git init`
   - `git add .`
   - `git commit -m "Exercícios das aulas 1 e 2"`
4. No GitHub, criem um repositório **vazio** e **público** chamado `exercicios-uf1.1` (sem README, sem *.gitignore*, sem *license*).
5. Liguem-no e enviem, com os três comandos que o GitHub mostra:
   - `git remote add origin https://github.com/O-VOSSO-UTILIZADOR/exercicios-uf1.1.git`
   - `git branch -M main`
   - `git push -u origin main`
6. Confirmem no GitHub que aparecem as pastas `sessao-01` e `sessao-02`.

_Atenção: o Git não guarda pastas vazias, e cada projeto tem o seu repositório. Nunca façam `git init` na pasta `dawfs`, que contém os dois._

### Missão 2: A Minha Cidade, Versão 3

1. Criem a pasta `sessao-03` e copiem para lá o `cidade.html` da aula 2.
2. Dentro de `sessao-03`, criem a pasta `imagens` e ponham lá o ficheiro [`cidade.svg`](./ex-003/imagens/cidade.svg) (ou uma fotografia vossa da cidade, com um nome sem espaços nem acentos, por exemplo `centro.jpg`).
3. Antes do `h1`, insiram a imagem com:
   - `src` (o caminho até à imagem);
   - um bom `alt` (o que se vê na imagem);
   - `width="240"` e `height="160"`.
4. Usem um `<abbr title="...">` numa abreviatura (por exemplo, *UNESCO* ou *CP*).
5. Usem um `<span lang="...">` numa palavra ou nome noutra língua (por exemplo, o nome romano da cidade, em latim, com `lang="la"`).
6. Acrescentem uma secção **Um ditado sobre a minha terra** com um ditado ou uma frase sobre a cidade (`blockquote`) e o autor (ou "Ditado popular"), os dois dentro de uma `div`.
7. Façam o ciclo de trabalho:
   - `git add .`
   - `git commit -m "Página da cidade versão 3"`
   - `git push`

### Missão 3: A Página dos Ovos Moles

1. Copiem para a pasta `sessao-03` o ficheiro [`ovos-moles.txt`](./ex-003/ovos-moles.txt) e, para a pasta `sessao-03/imagens`, a imagem [`ovos-moles.svg`](./ex-003/imagens/ovos-moles.svg).
2. Criem o ficheiro `ovos-moles.html` com a estrutura completa e passem para lá o texto, escolhendo o elemento certo para cada parte (título principal, capítulos, parágrafos).
3. No sítio indicado por `[imagem: ...]`, insiram a imagem com:
   - um **bom `alt`** (usem a descrição que lá está);
   - `width="240"` e `height="200"`.
4. Marquem a abreviatura **IGP** com `<abbr>` e o significado no `title`.
5. A citação da Dona Rosa vai num `blockquote`; o nome dela num parágrafo a seguir; os dois dentro de uma `div`.
6. Usem pelo menos um `<strong>` e um `<em>`, um comentário antes de cada capítulo e um rodapé com `<hr />` e `&copy;`.
7. Validem a página no [validador do W3C](https://validator.w3.org/#validate_by_input).
8. Façam o ciclo de trabalho, com a mensagem `Página dos ovos moles`, e enviem o link do vosso repositório ao formador.

**Critérios de sucesso:**

- [ ] A página tem a estrutura completa; o separador mostra "Ovos Moles de Aveiro".
- [ ] A imagem aparece e tem um `alt` que a descreve.
- [ ] Passar o rato por cima de "IGP" mostra "Indicação Geográfica Protegida".
- [ ] A citação está num `blockquote` e, com o nome da autora, dentro de uma `div`.
- [ ] O validador não mostra erros.
- [ ] O GitHub mostra a página e a imagem, e o `git log --oneline` mostra o commit `Página dos ovos moles`.

A vossa pasta `exercicios-uf1.1` deve ficar assim:

```
exercicios-uf1.1/            ← repositório Git, também no GitHub
├── sessao-01/
├── sessao-02/
└── sessao-03/
    ├── imagens/
    │   ├── cidade.svg
    │   └── ovos-moles.svg
    ├── cidade.html
    ├── ovos-moles.html
    └── ovos-moles.txt
```
